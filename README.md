# Multi-PDF RAG

A local, privacy-friendly AI assistant that lets you chat with multiple PDF documents at once. Upload your PDFs, and it retrieves relevant passages to answer questions with cited sources — powered by LangChain, a local Ollama LLM, HuggingFace embeddings, and a Chroma vector store. Built with a FastAPI backend and a Next.js frontend.
